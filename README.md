# Mawaqit Prayer Times Extension

A lightweight and feature-rich browser extension to display prayer times powered by [Mawaqit](https://mawaqit.net).

## Features
- 🕌 **Default Mosque**: Al-Haram Makkah (easily searchable and changeable to any mosque via Mawaqit link).
- 🌍 **Multi-language Support**: English, German, Arabic, Turkish, Urdu, Indonesian, and French.
- ⭐ **Pinned Mosques**: Quickly switch between your favorite mosques.
- 🔔 **Prayer Notifications**: Background alarms and notifications for prayer times.
- 🌙 **Dark & Light Theme**: Toggle between dark and light mode.

---

## Installation Guide (Developer Mode)

Since this extension is loaded locally, you can install it on any Chromium-based browser (Google Chrome, Microsoft Edge, Brave, Opera, etc.) in a few easy steps:

1. **Download / Clone** this folder to your computer.
2. Open your browser and navigate to the extensions page:
   - **Google Chrome**: Type `chrome://extensions` in the address bar.
   - **Microsoft Edge**: Type `edge://extensions` in the address bar.
   - **Brave**: Type `brave://extensions` in the address bar.
3. Enable **Developer mode** using the toggle switch (usually found in the top-right corner).
4. Click the **Load unpacked** button (top-left).
5. Select the folder containing this extension (`Mawaqit Erweiterung`).
6. 🎉 **Done!** The Mawaqit extension icon will appear in your toolbar. Pin it for quick access!

---

## Changing Your Mosque
1. Click the extension icon in your toolbar.
2. Click the **Change Mosque** button (or 🕌 button).
3. Search for your mosque on [Mawaqit](https://mawaqit.net), copy the page link from your browser's address bar, paste it into the extension input field, and click **Save** or **⭐ Pin**.
